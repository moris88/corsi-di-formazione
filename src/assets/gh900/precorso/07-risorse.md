## Pratica diretta su GitHub

- **GitHub Skills**: corsi interattivi gratuiti che si svolgono dentro un repository vero ([skills.github.com](https://skills.github.com)). Il più adatto per iniziare è *Introduction to GitHub*.
- **Un repository di prova**: crea un repository personale e usa tutte le funzioni di cui parla questo sito, dai rami alle issue ai workflow.
- **Sandbox dell'esame** di Microsoft: provala prima del giorno della prova.
