# Dominio 3: Claude Code (3,1%)

Dominio piccolo ma concreto. Per la CCDV-F basta una conoscenza operativa dei componenti di Claude Code, senza la profondità richiesta da un esame di architettura.

| Competenza | Peso sull'esame |
| --- | --- |
| Uso di Claude Code | 3,1% |

---

## 3.1 Uso di Claude Code (3,1%)

**Componenti principali**: regole, Skill, comandi, agenti, memoria degli agenti.

**Funzioni**: gestione delle sessioni, comandi slash integrati e personalizzati, modalità headless, modalità streaming, modalità automatica.

**Configurazione**: la gerarchia dei file `CLAUDE.md`, l'inizializzazione di un repository e il file `settings.json`.

---

## Ripasso rapido

- Sapere dove mettere un'istruzione: a livello di progetto, di utente o in una regola specifica.
- Sapere quando usare la modalità headless: script e pipeline senza interazione.
- Un comando personalizzato e una Skill non sono la stessa cosa: confronta quando caricano il loro contenuto.

Vedi anche: [Applicazioni e integrazione](./studio.html?doc=domain-2) per `CLAUDE.md` e `settings.json` come configurazione, e [Strumenti e MCP](./studio.html?doc=domain-8) per Skill e plugin.
