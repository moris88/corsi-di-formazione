# GitHub Foundations (GH-900) — Guida d'esame

## Introduzione

La certificazione **GitHub Foundations** si ottiene superando l'esame **GH-900**. Verifica la conoscenza di base di GitHub e delle sue funzionalità: Git, repository, strumenti di collaborazione, gestione dei progetti e pratiche di sviluppo moderne.

L'esame è pensato per **non sviluppatori, sviluppatori e tutti gli utenti di GitHub** che vogliono consolidare i fondamenti. Non richiede quindi di saper programmare: contano i concetti, i flussi di lavoro e il riconoscimento della funzione giusta per ogni situazione.

> **Stato dei materiali.** Questa sezione è in preparazione. Le pagine dei domini seguono la guida di studio Microsoft Learn aggiornata al **19 febbraio 2026**, con competenze in vigore da **gennaio 2026**. Allenamento e simulazione non sono ancora disponibili.

---

## Come si supera

- Per superare l'esame serve un punteggio di **700 o superiore**.
- Le competenze misurate sono sette, ciascuna con un peso espresso come intervallo percentuale.
- I punti elenco della guida ufficiale servono a illustrare *come* viene valutata ogni competenza: l'esame può trattare anche argomenti correlati.
- La maggior parte delle domande riguarda funzionalità disponibili a livello generale; possono comparire anche funzionalità in anteprima, se di uso comune.
- Se l'esame non è disponibile nella tua lingua, puoi chiedere 30 minuti aggiuntivi.

Durata, numero di domande e prezzo possono cambiare: controlla sempre la [pagina ufficiale della certificazione](https://learn.microsoft.com/credentials/certifications/github-foundations) prima di prenotare.

## Pesi dei domini

| Dominio | Competenza | Peso |
| --- | --- | --- |
| D1 | Informazioni di base su Git e GitHub | 25-30% |
| D2 | Collaborare con i repository GitHub | 10-15% |
| D3 | Collaborare con GitHub | 10-15% |
| D4 | Applicare procedure di sviluppo moderne | 10-15% |
| D5 | Gestire i progetti con GitHub | 5-10% |
| D6 | Informazioni su privacy, sicurezza e amministrazione | 10-15% |
| D7 | Esplorare la community di GitHub | 5-10% |

Il **Dominio 1** da solo vale circa un quarto dell'esame: parti da lì. Subito dopo, D2, D3, D4 e D6 pesano ciascuno fino al 15%.

## Piano di preparazione consigliato

1. **Prima di studiare**: apri un account GitHub gratuito. Gran parte delle competenze si capisce meglio provandola.
2. **Pre-corso** (se i concetti di base ti sono nuovi): fai il [test di ingresso](./studio.html?doc=precorso) e leggi solo i moduli che ti servono.
3. **Dominio 1**: Git, GitHub, GitHub Flow, Markdown.
4. **Domini 2 e 3**: struttura dei repository, issue, pull request, discussioni, Gist, Wiki e Pages.
5. **Dominio 4**: Actions, Copilot, Codespaces e github.dev.
6. **Domini 5, 6 e 7**: progetti, sicurezza e community.
7. **Ripasso**: consulta il [vocabolario](./studio.html?doc=vocabolario) e le [risorse di studio](./studio.html?doc=risorse).
