# Risorse di studio

Le risorse seguono la guida ufficiale Microsoft Learn, creata in collaborazione con GitHub.

## Percorsi ufficiali

- [Guida di studio per l'esame GH-900](https://learn.microsoft.com/credentials/certifications/resources/study-guides/gh-900): competenze misurate, pesi e log delle modifiche.
- [Pagina della certificazione GitHub Foundations](https://learn.microsoft.com/credentials/certifications/github-foundations): prezzo, lingue, prenotazione.
- Percorso di apprendimento **GitHub Foundations** su Microsoft Learn, in due parti (Parte 1 e Parte 2), anche con corso guidato da un istruttore.
- La **sandbox dell'esame** per provare l'interfaccia prima della prova.

## Community e supporto

- [GitHub Blog](https://github.blog) per novità e annunci.
- [GitHub Skills](https://skills.github.com) per esercizi pratici guidati.

## Consiglio

La documentazione di GitHub è in inglese e cambia spesso, in particolare per Copilot: se un nome o un piano non coincide con questi appunti, fa fede la documentazione ufficiale.
